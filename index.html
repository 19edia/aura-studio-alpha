@echo off
powershell.exe ...

#==AURA_POWERSHELL==

Add-Type -AssemblyName System.Drawing

# Interface WPF
# Processamento da imagem
# Aplicação do wallpaper via user32.dll

O BAT funciona como inicializador e carrega o PowerShell embutido no próprio arquivo. É por isso que o programa consegue continuar sendo distribuído como uma peça única.

Uma alternativa ao menu de Personalização

O AURA existe para facilitar a troca de wallpaper quando o usuário não quer ou não consegue usar o caminho tradicional do Windows. Ele não tenta “ativar” nada. Apenas oferece uma interface própria e usa mecanismos que já existem no sistema operacional.

PowerShell + WPF + APIs nativas

A interface é construída com WPF. O processamento e redimensionamento das imagens utiliza System.Drawing. Depois de preparar o arquivo, o programa ajusta as preferências de wallpaper do usuário e usa SystemParametersInfoW, em user32.dll, para pedir ao Windows que aplique a imagem.

Não é ativador de Windows

O AURA não fornece licença, não modifica o sistema de ativação e não remove avisos de ativação. A ferramenta se concentra exclusivamente em preparar e aplicar wallpapers. Simples. Milagrosamente, um projeto com escopo definido.
